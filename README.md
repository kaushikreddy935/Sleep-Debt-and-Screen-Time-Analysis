Sleep Debt and Screen Time Analysis

About the Project

This project analyzes the relationship between bedtime smartphone usage, sleep duration, sleep debt, and daytime fatigue using Exploratory Data Analysis (EDA).

Objectives

* Analyze the impact of bedtime screen time on sleep duration.
* Compare sleep patterns associated with different smartphone applications.
* Examine the relationship between sleep debt and fatigue.
* Analyze the influence of caffeine consumption and physical activity.
* Identify correlations between lifestyle habits and sleep patterns.

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

Visualizations

The project includes bar graphs, scatter plots, histograms, box plots, pie charts, and correlation heatmaps.

Conclusion

The project explores how smartphone usage and lifestyle habits are associated with sleep duration and fatigue, providing insights into digital habits and sleep patterns.
